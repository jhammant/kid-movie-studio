# kid-movie-studio

Make a real-looking movie with your kid, using AI and a plain wall.

A grown-up and a kid make the film as a team. The studio guides the grown-up through
each step (filming, the clean plate, the edit) and turns every creative decision into
a choice the kid makes from real previews: the title style, the channel name, the
transitions, the voices, the ending. The kid directs; the studio does the fiddly bits.

> Work in progress. See `docs/PROCESS.md` for how the first film was made.
